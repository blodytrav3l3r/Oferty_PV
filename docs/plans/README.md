# Archiwum planów i audytów

Plany i zadania znajdują się w [`archive/`](archive/) jako zapis historyczny. Nie traktuj ich jako bieżących wymagań ani kontekstu projektowego, chyba że użytkownik wyraźnie wskaże konkretny dokument lub poprosi o kontekst historyczny. Przed podjęciem decyzji sprawdzaj aktualny kod, konfigurację, testy i instrukcje projektu.

`_active-evidence.md` pozostaje poza archiwum jako ledger dowodów; jego ustalenia odnoszą się do wskazanych pomiarów i punktów odniesienia.
