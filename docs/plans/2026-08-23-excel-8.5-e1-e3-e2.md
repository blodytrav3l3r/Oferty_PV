## Zakres

### E1 — Kontrast DN tabs `0.75 / 0.18`

- **Plik:** `public/js/studnie/excelState.js:44-93` (`DN_COLORS`)
- **Zmiana:** `textDim 0.6 → 0.75`, `bg 0.12 → 0.18`, `borderDim 0.4 → 0.45` (6 wpisów: 1000/1200/1500/2000/2500/styczne)
- **Dlaczego 0.75/0.18:** minimalna zmiana dla WCAG 4.5:1. `0.8/0.20` dopiero gdy axe/Lighthouse nadal fail.
- **Weryfikacja:** `npm run test:a11y` + manual Lighthouse.

### E3 — Weryfikacja `max-width:140px` (bez zmian kodu)

- **Akcja:** tylko weryfikacja wizualna, brak refaktora.

### E2 — Empty-state z CTA

- **Pliki:** `public/js/studnie/excelTableBody.js:28` (`_excelRenderTbody`), `public/js/studnie/excelTabs.js:43` (focus po switch)
