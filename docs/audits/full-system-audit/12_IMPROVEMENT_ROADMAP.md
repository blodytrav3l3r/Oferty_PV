## Checkpoint wykonania

- **F0.** Pełny zapis kartoteki wymaga rewizji pobranej z serwera. Test PostgreSQL sprawdza, że stary lub równoczesny zapis dostaje HTTP 409, a klient, jego kontakty i powiązanie z ofertą pozostają w bazie. Przy wydaniu trzeba podnieść wersję zasobów frontendu, aby przeglądarki pobrały kod wysyłający rewizję.
- **F1–F3, częściowo.** Zabezpieczono odczyt wygasłego draftu przed usunięciem odświeżonej wersji, raport częściowego importu, audyt usuwania oferty studni i odrzucanie niekompletnych snapshotów. Zmieniono uprawnienia do blokad, kolejność autoryzacji względem parsera dużych żądań, obsługę błędów udostępnień, klucze cache, kontrolę originu i logowanie. Otwarte pozostają wspólna transakcja importu oferty ze zleceniami, ACL relacji zleceń, zakres ról bazy i pełny kontrakt OpenAPI.
- **F4 i F6, częściowo.** Ujednolicono kursor wyszukiwania, obsłużono remisy i puste pola w PostgreSQL oraz poprawiono zakres lokalnych dat w wydruku łącznym. Testy Playwright sprawdzają dostępność zalogowanej Kartoteki. Otwarte są pełna paginacja wyboru ofert w modalu, walidacja docelowych typów dat i relacji na istniejących danych oraz pomiary zapytań.
- **F7 i F8, częściowo.** Usunięto kod i test kolejki FTS5. Test indeksów GIN używa PostgreSQL, a skan powierzchni runtime jest bramką CI. Sprawdzono rzeczywisty kontekst budowy Docker oraz składnię i kontrakt instalatorów. Na pustym PostgreSQL 18.6 wykonano trzy migracje i dwukrotny import trzech aktywnych cenników (1023 pozycje). Próba `pg_dump` i `pg_restore` odtworzyła metadane wersji, liczby pozycji i rejestr migracji w osobnej bazie. Pełna instalacja na czystych hostach Windows i Linux oraz odtwarzanie operacyjne z backupu poza serwerem pozostają otwarte.
- **F5 i F9 pozostają otwarte.** W izolowanym S.O.K. zapisano i wyszukano oferty obu modułów, zweryfikowano wydruki PDF i DOCX dla obu ofert i wydruku łącznego oraz eksport XLSX trzech cenników. Do ponownej oceny potrzeba pozostałych poprawek, pomiarów na profilu 4 GB i próby przełączenia na docelowym środowisku.

`npm run validate` na PostgreSQL 18.6 zakończyło się wynikiem 5773 zaliczonych testów i czterech pominiętych przypadków. Trzy przypadki Docker preflight przeszły w osobnym uruchomieniu z Git Bash. Lokalna próba `pg_dump` i `pg_restore` potwierdziła odtwarzanie cenników. Przypadek Jest uruchamiający skrypt odtwarzania wymaga binariów PostgreSQL w systemie gospodarza.
